Methods for *Consistent Data-Driven Equations of State for Reacting and Nonideal Compressible Fluids* 
=====================================================================================================

Author: Evert Cornelis Bunschoten

Requires: [SU2](https://github.com/su2code/Su2.git) version 8.3.0 "Harrier", [SU2 DataMiner](https://github.com/EvertBunschoten/SU2_DataMiner.git) 

This repository contains the scripts, configurations, and instructions for the methods documented in the doctoral dissertation of E.C.Bunschoten titled *Consistent Data-Driven Equations of State for Reacting and Nonideal Compressible Fluids*. 
The instructions are provided chapter-wise, which each folder corresponding to a chapter in the manuscript. Each folder contains a README file that explains the contents of the folder and instructions on how to use the scripts to generate the results. 
The majority of the scripts are in Python and require the SU2 DataMiner software library. Installation instructions for SU2 DataMiner can be found on the [repository page](https://github.com/EvertBunschoten/SU2_DataMiner.git) and all the required python modules can most eaasily be isntalled through a virtual environment.
